# ADR-0003 — 不做官方云，只做 本地 + 自建

日期：2026-09-18 · 状态：已采纳

## 决策

产品形态为本地内核 + 用户自建服务器（Docker 单二进制）。不推出官方托管云。

## 理由

- 官方云在国内涉及 ICP/等保/内容审核/算法备案等合规主体风险，盈利前不背。
- 自建把数据主权交给用户，与"本地优先"宪法一致。
- 同步/发布服务与用户自建 infra 天然隔离，规避"同步和发布同通道"的国内合规问题。

## 后果

- 同步协议必须支持无服务器拓扑（LAN P2P、对象存储中转）作为兜底。
- 若未来推出托管云，仅作为海外版独立实体评估。
